## 新增

- **CSV、TSV 表格**：Chrome 會直接下載 `.csv`，現在文件裡的 CSV 連結會在右邊分割畫面顯示成表格。「直接開啟」「在新分頁開啟」，或從資料夾檢視、側邊欄「檔案」點 CSV 檔，會開啟表格頁，上方有「下載」可以存下原始檔案。逗號、分號、Tab 分隔自動判斷；不是 UTF-8 的檔案（例如 Excel 存的 Big5）會改用介面語言常用的編碼。
- **Excel 表格（`.xlsx`、`.xlsm`）**：同樣在右邊分割畫面或表格頁顯示，每個工作表一個分頁。日期、時間、百分比照 Excel 的格式顯示；公式顯示上次存檔時的結果。不支援舊的 `.xls`。檔案只在瀏覽器裡解析，沒有加任何外部套件。
- **`.txt` 和程式碼檔在分割畫面開啟**：連到 `.txt`，或你在設定頁加的程式碼類型（例如 `.py`）的連結，會在右邊顯示，程式碼有上色。
- **設定檔**：設定頁最下方可以把設定存成 JSON 檔，換電腦時再從檔案還原。不含最近開過的檔案和允許過的網站；還原時只採用格式正確的項目。
- **Mermaid 圖檔（`.mmd`、`.mermaid`）**：直接畫成圖，在右邊分割畫面也一樣；就算關掉 Mermaid 插件也會畫。

表格頁最多顯示 10,000 列，右邊分割畫面 1,000 列，超過時會註明總列數。直接在網址列開 `.csv`、`.xlsx` 仍會被 Chrome 下載，這點擴充沒辦法改。

開啟 Markdown 的速度和 1.1.1 相同。

### English

**New**

- **CSV and TSV tables**: Chrome downloads `.csv` files instead of showing them. A link to one now shows a table in the pane. "Open here", "Open in a new tab", the folder view and the Files tab open a table page with a Download button that saves the original file. Comma, semicolon and tab delimiters are detected; files that are not UTF-8 (such as Big5 from Excel) are read in the usual encoding for the interface language.
- **Excel workbooks (`.xlsx`, `.xlsm`)**: shown the same way, one tab per sheet. Dates, times and percentages appear as in Excel; formulas show the result saved with the file. The older `.xls` is not supported. Files are read inside the browser, with no added library.
- **`.txt` and code files in the pane**: links to `.txt` files, or to the code types added in Settings (such as `.py`), open in the pane, with code highlighted.
- **Settings file**: save your settings to a JSON file at the bottom of the settings page, and restore them on another computer. Recently opened files and allowed web sites are not included; only valid entries are restored.
- **Mermaid files (`.mmd`, `.mermaid`)**: drawn as a diagram, also in the pane, even with the Mermaid plugin switched off.

The table page shows up to 10,000 rows and the pane 1,000, with the total noted. Opening a `.csv` or `.xlsx` from the address bar is still a download; an extension cannot change that.

Markdown pages open as fast as in 1.1.1.
