## 新增

- 資料夾頁右邊的表格頁（CSV、Excel）多了「關閉 (Esc)」按鈕，按下去回到檔案清單；按 Esc 也可以。
- 設定頁「額外檔案類型」會列出已經內建、不用加的類型：Markdown、`.txt`、表格（CSV、TSV、Excel）、Mermaid。

## 修正

- 資料夾頁按瀏覽器的上一頁，現在會回到檔案清單或前一個打開的檔案，不會直接離開資料夾頁，也不會讓右邊變成空白。下一頁也一樣。
- 表格還沒載入完就按上一頁時，右邊不會卡在那個表格。

## 下載

- `anyread-md-1.2.1.zip`：手動安裝用，安裝方式見 README。
- `anyread-md-1.2.1-store.zip`：上傳 Chrome 線上應用程式商店用。

### English

**New**

- The table page (CSV, Excel) on the right of the folder page has "Close (Esc)", back to the file list; Esc works too.
- Settings, "Extra file types" lists the types that are built in and need no adding: Markdown, `.txt`, tables (CSV, TSV, Excel) and Mermaid.

**Fixed**

- The browser's Back button on the folder page now returns to the file list or the file opened before, instead of leaving the folder page or showing an empty right side. Forward works the same way.
- Pressing Back while a table is still loading no longer leaves that table on the right.
