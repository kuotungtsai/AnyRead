## 新增

- **Word 與 PowerPoint**：`.docx`、`.pptx` 不再只能下載。文件裡的連結會在右邊分割畫面顯示內容，「在新分頁開啟」、資料夾頁、側邊欄「檔案」會開在表格頁（一樣有「下載」）。Word 顯示標題、段落、清單、表格、超連結、圖片、註腳；PowerPoint 每張投影片依序顯示標題、項目文字、表格、圖片和講者備註，隱藏的投影片會標出來。只看內容，不重現排版；不支援舊的 `.doc`、`.ppt`。
- **資料與設定檔**：不用在設定頁加，就能看 JSON（`.json` 會自動排版）、JSONC、JSON5、JSON Lines、GeoJSON、YAML、TOML、INI、`.properties`、`.env`、`.log`，以及依檔名認得的 `.gitignore`、`.editorconfig`、`.npmrc`、`Dockerfile`、`Makefile`、`LICENSE` 等，都會上色。超過 1 MB 的檔案只顯示前 1 MB，並註明全長。
- **資料夾頁改成兩欄**：右邊是目前資料夾的檔案清單（或你點開的檔案），左邊是上一層，目前的資料夾會標出來。在右邊點資料夾往下一層；左邊的 `▸` 就地展開，「上一層資料夾」兩欄一起往上。瀏覽器的上一頁、下一頁會一步一步回去。資料夾頁一律先顯示檔案清單，不再自動打開 README。
- **顯示隱藏檔**：資料夾頁可以勾選「顯示隱藏檔」，列出 `.` 開頭的檔案和資料夾（會記住，側邊欄「檔案」也一樣）。
- **關閉 (Esc)**：資料夾頁右邊的檔案和表格右上角有「關閉」，或按 `Esc`，回到檔案清單（開著分割畫面時，`Esc` 先關分割畫面）。
- **左欄可以收起來**：資料夾頁左欄標題旁的 `«` 收起左欄，讓右邊和分割畫面更寬（會記住），`»` 再打開。
- **公式**：除了 `$…$`、`$$…$$`，也支援 GitHub 的 ` ```math ` 區塊和 `` $`…`$ ``。
- **側邊欄「檔案」**：點資料夾名稱開它的資料夾頁（按住 `Ctrl` 開在新分頁），點前面的 `▸` 就地展開；最上面的資料夾名稱也能點。

## 修正

- 連到其他網站的連結開在新分頁，正在看的文件留著。連到本機其他檔案（圖片、PDF、資料夾）的連結也一樣，照 README 原本的說明。
- 側邊欄「檔案」按 `↑` 會停在磁碟最上層，不會再跑到空白、回不來的 `file:///`。
- 重新整理資料夾頁時，不再先閃一下 Chrome 原本的檔案列表。
- 其他網頁用框架嵌入的 `.md`、`.txt` 照原樣顯示，AnyRead MD 只在自己的資料夾頁裡作用。
- `pnpm build` 產生的 zip 改名為 `anyread-md-<版本>.zip`，跟分享用的 zip 一致。

## 給開發者

- `pnpm demo` 產生一份虛構的團隊手冊，每個功能一個例子，可以直接試用。
- `pnpm test:e2e` 是瀏覽器測試（第一次會下載 Chrome for Testing），也支援無畫面的 Linux。
- 每次 commit 會自動檢查是否含有個人或敏感資料。

### English

**New**

- **Word and PowerPoint**: `.docx` and `.pptx` files are no longer download-only. Links to them show their content in the pane; "Open in a new tab", the folder page and the Files tab open them on the table page (with Download). Word shows headings, paragraphs, lists, tables, links, pictures and footnotes; PowerPoint shows each slide in order with its title, text, tables, pictures and speaker notes, hidden slides marked. The content only, not the layout; the older `.doc` and `.ppt` are not supported.
- **Data and settings files**: without adding them in Settings, JSON (`.json` pretty-printed), JSONC, JSON5, JSON Lines, GeoJSON, YAML, TOML, INI, `.properties`, `.env` and `.log` files are shown highlighted, as are files known by name such as `.gitignore`, `.editorconfig`, `.npmrc`, `Dockerfile`, `Makefile` and `LICENSE`. A file over 1 MB shows its first 1 MB, with its full size noted.
- **Two-column folder page**: the main column lists the current folder (or shows the file you picked), the left column the folder above, with the current folder marked. A folder in the main column opens one level down; `▸` on the left opens a folder in place, and "Parent folder" moves both columns up. The browser's Back and Forward step through it all. The folder page always opens on its file list; a README is no longer opened by itself.
- **Show hidden files**: a box on the folder page lists files and folders whose names start with `.` (remembered; the side bar's Files tab follows it).
- **Close (Esc)**: a file or table on the right of the folder page has Close at its top right, or press `Esc`, to go back to the file list (with the pane open, `Esc` closes that first).
- **The left column hides**: `«` next to its name hides it for a wider file and pane (remembered); `»` brings it back.
- **Math**: besides `$…$` and `$$…$$`, GitHub's ` ```math ` blocks and `` $`…`$ ``.
- **Side bar Files tab**: a folder's name opens its folder page (`Ctrl`+click: a new tab), the `▸` in front opens it in place, and the folder name at the top is a link too.

**Fixed**

- Links to other web sites open in a new tab, so the document stays; links to other local files (pictures, PDF, folders) do too, as the README already said.
- `↑` in the Files tab stops at the top of the drive instead of an empty `file:///` with no way back.
- Reloading the folder page no longer flashes Chrome's own listing.
- `.md` and `.txt` files framed by other pages stay as they are; AnyRead MD works in frames only on its own folder page.
- `pnpm build` names its zip `anyread-md-<version>.zip`, like the shareable one.

**For developers**

- `pnpm demo` writes a made-up team handbook with an example of every feature, to try by hand.
- `pnpm test:e2e` runs the browser tests (Chrome for Testing is downloaded once), also on Linux without a display.
- Every commit is checked for personal or sensitive data.
