## 改名：AnyRead

AnyRead MD 改名為 **AnyRead – 瀏覽與閱讀本機檔案**（英文：AnyRead – Browse & Read Local Files）。它早就不只看 Markdown：CSV、Excel、Word、PowerPoint、JSON、YAML 這些 Chrome 原本只會下載的檔案都能打開，最常用的也是瀏覽整個資料夾，名字裡的「MD」反而讓人以為它只能讀 Markdown。

- **新圖示**：資料夾裡露出一頁寫著 AnyRead 的文件。顏色和原本一樣，深色底配黃色。
- **介面和文件**：介面、README、隱私權說明、商店介紹裡的「AnyRead MD」都改成「AnyRead」；工具列上的圖示也改叫「AnyRead 圖示」。
- **商店介紹**：簡短說明和介紹改成先講瀏覽資料夾，支援的檔案用類別介紹（文件、試算表、簡報、資料檔）；宣傳圖換成資料夾頁。

### 不變的

- 擴充功能還是同一個：已經安裝的不用重裝，設定、最近開過的檔案、允許過的網站都留著。
- 以前存的設定檔照樣可以「從檔案還原」。
- 功能沒有改變。GitHub 專案改名為 AnyRead（舊網址會自動轉過去），zip 檔名改成 `anyread-<版本>.zip`。

## 下載

- `anyread-1.4.0.zip`：手動安裝用，安裝方式見 README。
- `anyread-1.4.0-store.zip`：上傳 Chrome 線上應用程式商店用。

### English

**New name: AnyRead**

AnyRead MD is now **AnyRead – Browse & Read Local Files**. It has long been more than a Markdown reader: CSV, Excel, Word, PowerPoint, JSON and YAML files, which Chrome would only download, open too, and browsing a whole folder is what it is used for most. The "MD" made it look like it only read Markdown.

- **New icon**: a folder with a page showing AnyRead. Same colors as before, yellow on dark.
- **Interface and documents**: "AnyRead MD" is now "AnyRead" in the interface, the READMEs, the privacy policy and the store listing; the toolbar button is called the "AnyRead icon".
- **Store listing**: the summary and description now start with browsing folders and describe the files by kind (documents, spreadsheets, slides, data files); the promo images show the folder page.

**What stays the same**

- It is the same extension: nothing to reinstall, and your settings, recent files and allowed sites stay.
- Settings files saved before still load with "Restore from a file".
- No features changed. The GitHub project is now AnyRead (the old address redirects), and the zips are named `anyread-<version>.zip`.
