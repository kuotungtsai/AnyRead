## 改變

- **資料夾頁變成專案**：打開的資料夾就是專案的最上層。左欄是這個資料夾自己的樹狀目錄，不再列出旁邊不相干的資料夾；往下走或打開檔案時，樹會展開到你所在的資料夾或打開的檔案、標出來，資料夾很多時也會捲到看得見的地方。「上一層資料夾」只到專案最上層為止，點左欄標題回到最上層。要看專案外面，點上方路徑裡專案以上的資料夾，它就成為新的專案。專案記在網址後面（例如 `#root=../`），重新整理也不會跑掉。
- **從 Markdown 檔過去也一樣**：側邊欄「檔案」裡的資料夾，會以「檔案」最上面那個資料夾為專案打開。
- **想要以前的樣子**：設定頁「其他」新增「全域資料夾瀏覽」（預設關閉）。打開後，左欄回到顯示上一層資料夾，「上一層資料夾」可以一路往上。
- 磁碟最上層（例如 `D:`）現在直接列出磁碟裡的檔案，不再要你先在左邊點一個。

## 修正

- 資料夾頁右邊顯示圖片或 PDF 時，按 `Esc` 沒有反應。現在會回到檔案清單，點進圖片後再按也一樣。PDF 剛打開時也可以；但如果你點進 PDF 裡（例如用鍵盤捲動），`Esc` 會被 Chrome 的 PDF 檢視器接走，這時請用左欄或瀏覽器的上一頁。
- 商店列出的語言改成和介面一致：English、日本語、한국어、简体中文、繁體中文。之前會列出其實沒有介面翻譯的烏克蘭語。

### English

**Changed**

- **The folder page is a project**: the folder you open is the project's top. The left column is that folder's own tree, without the unrelated folders around it; as you go down or open a file, the tree opens to that folder or file, marks it, and scrolls to it in a long tree. "Parent folder" stops at the project's top, and the name above the tree goes back there. To look outside the project, click a folder above it in the path at the top: it becomes the new project. The project is kept in the address (such as `#root=../`), so a reload keeps it.
- **From a Markdown file too**: a folder in the side bar's Files tab opens with the folder at the top of that tab as its project.
- **For the folder page as it was**: Settings, More, has a new "Browse all folders" switch (off by default). On, the left column lists the folder above again, and "Parent folder" goes all the way up.
- The top of a drive (such as `D:`) now lists the drive's files, instead of waiting for you to pick a folder on the left.

**Fixed**

- `Esc` did nothing while the folder page showed a picture or a PDF. It now goes back to the file list, also after you click in the picture, and right after a PDF opens. Once you click inside a PDF (to scroll it with the keyboard, say), Chrome's PDF viewer takes `Esc`; use the left column or the browser's Back then.
- The store lists the languages the interface has: English, Japanese, Korean and both Chinese. It used to list Ukrainian, which has no interface translation.
